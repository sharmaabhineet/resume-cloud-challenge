Using Node Ordering to Improve Structure MCMC for Bayesian Model Averaging

Given the super-exponential structure space, finding the structure that best explains modest data is computationally demanding. This thesis proposes a Markov Chain Monte Carlo (MCMC) simulation approach that leverages node ordering to improve mixing and more accurately estimate the posterior distribution of structural features.
