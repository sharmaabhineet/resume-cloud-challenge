Master's Thesis

Using node ordering to improve Structure MCMC for Bayesian model averaging
Download
Addresses an important problem of estimating Bayesian model structures using Bayesian model averaging approach. Owing to the super exponential structure space, it is a challenging task to find a structure that best explains the data. This is further worsened when the amount of data available is modest. This thesis proposes a Markov Chain Monte Carlo(MCMC) simulation approach in order to use Bayesian Model averaging technique to estimate posterior of certain features.
