Engineering Principles

Start simple

Choose modularity first and distribution only when scale, teams, or failure modes justify it.

Measure before optimizing

Use production evidence to find real bottlenecks, then make targeted performance improvements.

Design for operations

Favor systems that are observable, debuggable, recoverable, and understandable under pressure.

Use AI as leverage

Let tools accelerate implementation while judgment, review, and ownership stay with the engineer.

Master’s Thesis

Using Node Ordering to Improve Structure MCMC for Bayesian Model Averaging

Addresses the challenging problem of estimating Bayesian network structures via Bayesian model averaging. Given the super-exponential structure space, finding the structure that best explains modest data is computationally demanding. This thesis proposes a Markov Chain Monte Carlo (MCMC) simulation approach that leverages node ordering to improve mixing and more accurately estimate the posterior distribution of structural features.
